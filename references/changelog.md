## v1.1.2 — 2026-11-01

**同步器取文件改走 `Contents + Accept: raw`**（原走 `git/blobs` JSON base64）。

- `git/blobs` 不认 `raw`，实际仍返回 base64 JSON：1.5MB 文件要传 2.0MB，且在本机慢网下反复截断。
- 改用 `GET /contents/{path}` + `Accept: application/vnd.github.raw`：直接拿裸字节，
  **少 25% 流量、少一次元数据请求**；实测 1.5MB 模板 53s 完成、sha256 对齐。
- 保留 JSON 退化分支（若服务端仍返回 JSON 则解 base64）与 3 次重试、sha 强校验。
- 实测记录：首次尝试仍可能因网络闪断失败一次，第 2 次成功（全流程 134s）。

## v1.1.1 — 2026-11-01

**模板瘦身（不改版式、不改品牌元素）**：`assets/company-template.pptx` 6.11 MB → **1.50 MB**。

- 只重编码 `ppt/media/image5.png`（3430×1386 RGBA，4.09MB → 1715×693 PNG8，350KB）。
  该图仅用于 `自定义版式`（本就禁用）的模板效果总览，与内容页无关。
- **其余部件（母版、7 个版式、封面/正文底图、logo）逐字节未动**；渲染差异仅 1.4% 像素（文字边缘重采样）。
- 起因：本机到 `api.github.com` 约 21 KB/s 且**服务端不支持 Range 续传**，6MB 单连接会在 ~4 分钟处被截断，
  首次真实拉取即失败（`IncompleteRead` / sha 不符）。1.5MB 约 70 秒可完成。
- 顺带把下载器改为 `Accept: raw` + 256KB 分块读 + 3 次重试 + sha 强校验，慢网下不再整轮失败。

## v1.0.2 — 2026-11-01

修复多设备链路的两个缺陷，规则正文不变。

- **修复**：`scripts/sync_rules.py` 此前未纳入 `manifest.files`，导致新设备自举时下载 404，
  且各设备的同步器永远无法随版本演进（逻辑会分叉）。现纳入受管文件。
- **新增** `bootstrap.sh`：无项目目录的新设备可一行从 GitHub 完成安装。
- **调整** 推送顺序为「先内容文件、最后 manifest.json」，避免客户端读到新版本号但内容未落盘。
- **文档** README / SKILL.md 的安装与发布流程改为使用 `publish_rules.py`，不再手算 sha256。

## v1.0.0 — 2026-11-01

首版。基于《DTB项目专项汇报V1.8.pptx》47 页全量实测（520 个形状 / 43 张表格 / 8 个图表 /
18 个版式）归纳，不是凭观感制定。

### 定稿的四条硬约束

- **一套网格**：画布 1280×720px；版心 79.1→1205.3 / 134.5→654.2；栏间距 24px
- **三档字号**：28 / 16 / 12 pt（原稿实际 17 种）
- **一种字体**：微软雅黑（原稿 5 种写法：微软雅黑 / Microsoft YaHei / 等线 / 宋体 / Arial，
  另有 Calibri Light 页码）
- **一套色板**：9 主色 + 2 辅色；禁用 10 个手工近似色

### 主要裁决

| 对象 | 原稿 | 定为 | 依据 |
|---|---|---|---|
| 页标题位置 | 5 种偏移 | L79.1 / T50.1 / W1126.2 / H52.3 | 35/43 页已在此位，模板 lstStyle 原生定义 |
| 正文字号 | 14 / 12 / 16 并存 | 12 | 与表格唯一档位对齐 |
| 表格字号 | 8 种（9–20pt） | 12 | 表格最高频值（864 次） |
| 表头底色 | 8 种 | #0084D5 底白字 | 主题定义色；#008BCE 是手工近似值 |
| 页码 | 25 页有 / 22 页无 / 第 2 页重复 | 除封面每页 1 个 | 汇报可追溯的最小要求 |
| 版式 | 18 个版式只用 5 个 | 只留 4 个 | 其余 13 个是风格漂移主因 |

### 配套工具

- `ppt_format_check.py`：实测原稿 **2,877 处偏差**（字号 1903 / 字体 743 / 禁用色 170 /
  缺页码 22 / 表头底色 18 / 表头字重 15 / 标题位置 5 / 版式越界 1）
- `apply_format.py`：一键处理后降到 **1 处**（仅剩 p46 版式越界这类需人工删页的项）；
  字号被放大的页面单独列出供人工复核溢出风险

### 已知边界

- 不处理图表内部字体（需改 chart XML，风险高，留待人工）
- 不自动删页、不调整文字内容、不改图片
- 字号放大后可能溢出文本框，脚本只报警不自动缩排
