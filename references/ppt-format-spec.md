# PPT 输出规范（伊利默认模板 + 咨询式组件系统）v2.0.1

> **适用对象**：所有 PPT 材料（DTB 专项汇报、年度汇报、季度复盘、专项方案、培训课件）
> **基准模板**：`assets/company-template.pptx`（即《公司模板.pptx》，v1.1 起为唯一默认模板）
> **实测基线**：《DTB项目专项汇报V1.8.pptx》（47 页，2025-12-25）
> **制定日期**：2026-11-01（v1.0 基于 V1.8 实测；v1.1 对齐公司模板几何）
> **一句话原则**：**模板定品牌，组件定表达；中文微软雅黑，英文/数字Verdana；字号遵循咨询式层级，颜色遵循当前模板。**

## 0. 模板与组件库（最高优先级）

**任何 PPT 输出，用户未明确指定其他模板时，一律从 `assets/company-template.pptx`（伊利模板）起稿，不得自选或自建模板。**

咨询式组件库与模板完全分离：组件库只提供可复用的页面结构、逻辑图、流程、矩阵、图表、框架、信息图和图标；允许拆解、组合、重排，但不得带入原咨询公司品牌母版、logo、公司名、版权、品牌页脚、专属命名或品牌色身份。

| 编号 | 规则 |
|---|---|
| T1 | 起稿必须 `python3 "$SK/scripts/new_deck.py" <输出.pptx>`，由脚本复制模板生成，**不要新建空白演示文稿** |
| T2 | 只允许使用模板自带的 7 个版式（见第 2 节），禁止新建版式、禁止改母版与版式几何 |
| T3 | 模板的底图、logo（右上）、左上蓝色竖条、浅色水印**均属品牌资产，不得删除、遮盖或改色** |
| T4 | 用户明确指定别的模板时，才切换；组件库仍可调用，但所有颜色必须映射到该模板色系 |
| T5 | 检查已有文件时，若版式名不在模板清单内（第 2 节），判定为「模板不符」，先换模板再谈格式 |
| C1 | 默认组件库为去品牌化咨询式组件库；只取组件，不套咨询公司母版 |
| C2 | 组件选择遵循“内容意图 → 最简合适元素”，禁止为装饰而复杂化 |
| C3 | 组件必须尽量保持原生可编辑；不得用截图代替可编辑图表/Shape |
| C4 | 默认颜色映射到伊利色系；用户指定其他模板时映射到用户模板色系 |
| C5 | ChatGPT环境优先调用Library：`/DTB/PPT组件库/consulting-components-sanitized.pptx`；仓库具备同名资产时优先本地资产 |

模板文件自身受版本管理：`manifest.json` 记录其 sha256，`sync_rules.py --update` 会同步到
技能目录 `assets/company-template.pptx`。模板一旦更新，全设备随之更新。

## 0.1 总则

| 编号 | 规则 | 说明 |
|---|---|---|
| G1 | 双字体映射：**中文=微软雅黑；英文与数字=Verdana** | OOXML中 eastAsia=微软雅黑，latin=Verdana；页码、图表、表格同样遵守 |
| G2 | 字号遵循咨询式层级 | 文件标题18、文件副标题16、封面信息10；章节标题/副标题38.5；引述高亮28、引述内容24；页面标题/副标题24；标题文字/正文/项目符号/图表文字14；图表标签/来源9；页脚6.5 pt |
| G3 | 标题一律**加粗**；正文一律**不加粗**（表头、卡片标题、关键数字除外） | 加粗只承担层级，不承担强调；强调用颜色 |
| G4 | 一个对象只用一套规范 | 同类元素（页标题、表头、页脚码、图注）在全篇位置、字号、颜色完全一致 |
| G5 | 放不下先改结构 | 列多→拆表；字多→提炼要点；不通过缩字号/缩行距解决 |

**基准换算**：本规范坐标以 1280×720 px 渲染坐标给出，PowerPoint 中按 `1 px = 0.02646 cm` 换算（3 位小数已给全）。页面实物尺寸 33.87 × 19.05 cm（16:9）。

## 3. 字体与字号

### 3.1 字体

**中文：微软雅黑；英文与数字：Verdana。** 含正文、标题、表格、图表标签、页码、SmartArt、组合图形内文字。
- OOXML字体映射：`a:ea` 使用微软雅黑；`a:latin` 使用 Verdana。
- 中文与英文/数字混排时无需拆成不同文本框，通过字体映射自动显示。
- 字间距默认（不加宽、不紧缩）；正文禁用斜体。

### 3.2 字号（咨询式层级）

| 层级 | 字号 | 用途 |
|---|---:|---|
| 文件标题 | 18 pt | 文件级标题 |
| 文件副标题 | 16 pt | 文件级副标题 |
| 封面信息 | 10 pt | 日期、部门等 |
| 章节页标题 | 38.5 pt | 章节主标题 |
| 章节页副标题 | 38.5 pt | 章节副标题 |
| 引述高亮 | 28 pt | 引语重点 |
| 引述内容 | 24 pt | 引语正文 |
| 页面标题 | 24 pt | 正文页标题 |
| 页面副标题 | 24 pt | 页面副标题 |
| 标题文字 | 14 pt | 模块标题 |
| 正文文字 | 14 pt | 正文 |
| 一级/二级/三级项目符号 | 14 pt | 列表 |
| 图表文字 | 14 pt | 图表主文字 |
| 图表标签 | 9 pt | 数据标签 |
| 来源主题词 | 9 pt | 来源、注释 |
| 页脚 | 6.5 pt | 页脚信息 |

**模板与内容字号冲突时**：母版几何与品牌元素不动；新增或修改的内容文字按本表执行。模板品牌底图中的文字保持原样，不作为内容文字字号特例。

**执行细则**
- 表头、数据和项目符号统一 14 pt；图注、来源与图表标签 9 pt；页脚页码 6.5 pt。
- 字号由语义角色决定，不按旧字号大小猜测。页面标题、章节页标题按角色直接归位。
- **存量稿字号吸附规则**：非标题文字若已在层级内则不动；不在层级内则吸附到**最近层级**（等距时取小，避免撑破版面）。15.5→16、10.5→10、11.5→10、20→18、36→38.5 均属正常吸附。吸附结果计入报告「字号吸附」，放大者额外进溢出风险页清单。
- **超出 5–60 pt 的字号不吸附**，保留原值并报告「字号待确认」，交人工判断（多为图标内嵌数字、艺术字或特殊图形）。
- 需要逐字控制、不允许吸附时，改版器加 `--no-snap`，此时仅精确等于层级的字号会被保留，其余全部报告。
- 关键数字按正文 14 pt 表达；仅明确引述场景使用 28/24 pt。
- 同页只保留业务表达所需的层级；放不下先拆表、拆页或重排，不缩字号。

### 3.3 段落

| 属性 | 值 |
|---|---|
| 对齐 | 正文左对齐（**禁用两端对齐**，中文会松散）；卡片内可居中；表格数字右对齐 |
| 段前 / 段后 | 0 / 6 pt |
| 行距 | 见 3.2；正文 1.5 倍，表格与图注 1.0 |
| 缩进 | 无首行缩进；条目用悬挂缩进 0，符号见 3.4 |
| 文本框 | 自动换行开启，垂直居中（标题）或顶端对齐（正文）；内边距左右 0.25 cm、上下 0.13 cm |

### 3.4 列表符号

- 一级条目：`■` + 空格，`#0084D5`，14 pt（颜色跟随文字亦可）
- 二级条目：`·` 或 `–`，同正文色
- 条目编号：`1、2、3、`（中文顿号），与正文同字号
- 不用系统默认圆点 `•`（字号不一致时错位）

## 5. 表格规范

原稿 43 张表格存在 8 种表头底色、9–20 pt 八种字号、宽度 270–1214 px 的混乱，以下为唯一标准。

### 5.1 结构

| 项 | 规范 |
|---|---|
| 位置 | L 55.0，宽 1151.0（通栏）或按 1.3 分栏取宽；**不得左伸到 15.6、右伸到 1236** |
| 列数 | ≤ 12 列；超过则拆为两张表或改为"要点 + 数据卡" |
| 表头行 | 高 **36 px**；`#0084D5` 底、白字 **14 pt 加粗**、居中 |
| 数据行 | 高 **28 px**；14 pt 常规、`#000000`；单行显示，不换行 |
| 隔行 | 偶数行底 `#F4F4F4`（无隔行时用细横线代替，二者择一，全篇统一） |
| 合计行 | `#DDEBF7` 底，14 pt 加粗 |
| 边框 | **无竖线**；横线 0.75 pt `#D9D9D9`；外框不描边 |
| 内边距 | 左右 8 px（0.21 cm）、上下 4 px（0.11 cm） |
| 行数 | ≤ 15 行；超出拆表或转横向页 |

### 5.2 对齐与格式

| 内容类型 | 对齐 | 格式 |
|---|---|---|
| 文字（营销总部、区县、产品名） | 左 | — |
| 数值（销量、金额、门店数） | 右 | 千分位，1 位小数：`1,234.5` |
| 比率 / 达成率 | 居中 | 1 位小数：`103.0%` |
| 排名 / 序号 | 居中 | 整数 |
| 空值 | — | `—`（半角破折号），不留空、不写 0 |

### 5.3 单位

- 单位写在**表头**：`销量（亿元）`、`门店数（家）`，不在单元格内重复。
- 全表统一口径单位，不混用"万元/亿元"。

## 6. 图表规范

原稿 8 个图表均无原生标题、配色与位置各异，以下为标准。

### 6.1 位置与尺寸

| 布局 | 宽 (px) | 高 (px) | 位置 |
|---|---|---|---|
| 通栏单图 | 1151.0 | 240 / 280 / 320 | L 55.0，T 由内容区顶起 |
| 双栏并排 | 563.5 | 240 | 左右各一，间距 24 |
| 双图上下 | 1151.0 | 220 × 2 | 间距 24 |

### 6.2 元素

| 元素 | 规范 |
|---|---|
| 图表标题 | **关闭**（结论由页标题/导语承担） |
| 图例 | 顶部、靠左、14 pt；单系列不显示图例 |
| 数据标签 | 9 pt；仅标注首末值或极值，不全标 |
| 网格线 | 仅水平，0.75 pt `#E6E6E6`；无竖直网格线 |
| 坐标轴 | 轴线 0.75 pt `#BFBFBF` 或隐藏；刻度标签 9 pt `#7F7F7F` |
| 数据表 | 关闭（改用下方表格） |
| 序列配色 | 依序 `#0084D5` → `#BFBFBF` → `#78BE20` → `#C00000` |
| 数值格式 | 整数 `0`；负值 `0;[Red]-0`；百分比 `0.0%` |
| 图表区 | 无填充、无边框 |

### 6.3 常用组合

- **目标 vs 达成**：柱（目标，`#BFBFBF`）+ 柱（达成，`#0084D5`），标签只标达成。
- **月度趋势**：折线 `#0084D5`，2.25 pt，无数据点标记。
- **结构占比**：条形图优于饼图；饼图最多 5 块，其余合并为"其他"。

## 10. 文字写法（易错项）

| 项 | 规范 | 原稿问题示例 |
|---|---|---|
| 数字与单位 | 紧贴，不加空格 | `16. 62亿元` → `16.62亿元` |

## 14. 咨询式组件库选择规则（v2.0新增）

先判断页面要表达的“逻辑任务”，再选组件。组件库是资产池，不是固定页面模板。

| 页面意图 | 优先组件 |
|---|---|
| 核心结论 / Executive message | 结论页、结构化文本 |
| 战略全景 / Target operating model | 战略框架、分层架构、系统图 |
| 原因拆解 | 逻辑树、驱动树、鱼骨/因素图 |
| 增长来源 | 驱动树、瀑布图 |
| 市场/对象分层 | 2×2、3×3矩阵 |
| 趋势 | 折线图、面积图 |
| 横向比较 / 排名 | 横向条形图 |
| 多指标比较 | 柱状图、雷达图 |
| 构成 | 堆积图、100%堆积图 |
| 流程 | 流程图、Chevron |
| 阶段演进 | 时间线、成熟度阶梯 |
| 责任体系 | 组织图、角色模型、RACI |
| 路线图 | Roadmap、甘特 |
| 闭环 | 循环图、飞轮 |
| 多因素关系 | 关系图、生态图 |
| 多观点归纳 | 文本卡片、多列结构 |

**选择原则**：
1. 一页一个核心观点，标题优先写结论。
2. 优先使用最简单、最容易解释清楚的组件。
3. 组件可跨页拆解、重组；不得机械套整页。
4. 原组件中的咨询公司品牌色只保留功能逻辑：主色/辅助色/风险/预警/正向/中性。
5. 落到伊利模板时，颜色映射为伊利模板色系；红/橙/黄等强调色仅在风险、预警、异常、热图等有明确业务含义时使用。
6. 所有图表、图形、表格优先保持可编辑。
