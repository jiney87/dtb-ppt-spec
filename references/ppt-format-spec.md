# PPT 输出规范（默认模板：公司模板.pptx）v1.1.0

> **适用对象**：所有 PPT 材料（DTB 专项汇报、年度汇报、季度复盘、专项方案、培训课件）
> **基准模板**：`assets/company-template.pptx`（即《公司模板.pptx》，v1.1 起为唯一默认模板）
> **实测基线**：《DTB项目专项汇报V1.8.pptx》（47 页，2025-12-25）
> **制定日期**：2026-11-01（v1.0 基于 V1.8 实测；v1.1 对齐公司模板几何）
> **一句话原则**：**一套网格、三档字号、一种字体、一套色板。** 任何新增页面只能在这四个约束内排版，不得为"放得下"而破例——放不下改结构，不改规范。

---

## 0. 默认模板（最高优先级）

**任何 PPT 输出，一律从 `assets/company-template.pptx` 起稿，不得自选或自建模板。**
用户未特别指定模板时，这就是默认值，不需要询问。

| 编号 | 规则 |
|---|---|
| T1 | 起稿必须 `python3 "$SK/scripts/new_deck.py" <输出.pptx>`，由脚本复制模板生成，**不要新建空白演示文稿** |
| T2 | 只允许使用模板自带的 7 个版式（见第 2 节），禁止新建版式、禁止改母版与版式几何 |
| T3 | 模板的底图、logo（右上）、左上蓝色竖条、浅色水印**均属品牌资产，不得删除、遮盖或改色** |
| T4 | 用户明确指定别的模板时，才切换；切换后仍需满足本规范的字体/字号/色板三约束 |
| T5 | 检查已有文件时，若版式名不在模板清单内（第 2 节），判定为「模板不符」，先换模板再谈格式 |

模板文件自身受版本管理：`manifest.json` 记录其 sha256，`sync_rules.py --update` 会同步到
技能目录 `assets/company-template.pptx`。模板一旦更新，全设备随之更新。

## 0.1 总则

| 编号 | 规则 | 说明 |
|---|---|---|
| G1 | 全篇唯一字体：**微软雅黑** | 中文、西文、数字、页码、图表标签全部一致；不出现 Microsoft YaHei / 等线 / 宋体 / Arial / Calibri Light |
| G2 | 全篇字号只用 **3 档：28 / 15 / 12 pt** | 含标题。封面/间隔页/结语页沿用模板原生字号（见 3.2），不在三档内另设。禁设 10、11、13、16、18、20、24、36、40、44 pt 等中间档 |
| G3 | 标题一律**加粗**；正文一律**不加粗**（表头、卡片标题、关键数字除外） | 加粗只承担层级，不承担强调；强调用颜色 |
| G4 | 一个对象只用一套规范 | 同类元素（页标题、表头、页脚码、图注）在全篇位置、字号、颜色完全一致 |
| G5 | 放不下先改结构 | 列多→拆表；字多→提炼要点；不通过缩字号/缩行距解决 |

**基准换算**：本规范坐标以 1280×720 px 渲染坐标给出，PowerPoint 中按 `1 px = 0.02646 cm` 换算（3 位小数已给全）。页面实物尺寸 33.87 × 19.05 cm（16:9）。

## 1. 页面与网格

### 1.1 画布

| 项目 | 值 |
|---|---|
| 比例 / 尺寸 | 16:9，**33.87 × 19.05 cm**（1280 × 720 px） |

### 1.2 版心（安全区）

```

│  ▌ 左上蓝色竖条（底图，约 0–60 × 20–100）    │
│ 66.0  ┌────────────────────┐                │  50.0  ← 标题带

```

> 标题框（66.0）比内容区（55.0）右移 11 px，是为避让左上角蓝色竖条——**这是模板设定，
> 不要为了"左对齐"去挪占位符**。

| 元素 | 左 (px / cm) | 上 (px / cm) | 宽 (px / cm) | 高 (px / cm) |
|---|---|---|---|---|
| 版心（内容区） | 55.0 / 1.455 | 135.0 / 3.572 | 1151.0 / 30.454 | 520.0 / 13.758 |
| 页标题框 | 66.0 / 1.746 | 50.0 / 1.323 | 1030.0 / 27.252 | 52.0 / 1.376 |

- 以上四值全部取自模板「正文页1」占位符**原值**，脚本按此校验；改模板才改这里。

栏间距固定 **24 px（0.635 cm）**，栏宽由版心宽 1151.0 px 均分：

| 6 栏 | 171.8 | 4.546 | KPI 指标条 |

**纵向节奏**：模块之间 24 px；同一模块内段落之间 16 px；卡片内边距上下 12 px、左右 16 px。

## 3. 字体与字号

### 3.1 字体

**微软雅黑**，全篇唯一。含：正文、标题、表格、图表标签、页码、SmartArt、组合图形内文字。
- 中英文混排不切换字体（数字、英文一律跟随微软雅黑）。
- 字间距默认（不加宽、不紧缩）；正文禁用斜体。

### 3.2 字号（仅 3 档）

| 档 | 字号 | 加粗 | 行距 | 用途 |
|---|---|---|---|---|
| **L** | **28 pt** | 必须 | 1.0 | 页标题、结论页金句 |
| **M** | **15 pt** | 视层级 | 1.2 | 栏目标题、卡片标题、导语、关键数字、要点条目、副标题 |
| **S** | **12 pt** | 不加粗（表头、合计行除外） | 1.5（正文）/ 1.0（表格、图注、注释） | 正文段落、表格全部文字、图注、单位、页码 |

**特例页（不占三档，用模板原生值，不得改动）**

| 页面 | 元素 | 字号 | 说明 |
|---|---|---|---|
| 封面 | 主标题 | 48 pt 加粗 | 模板占位符原生 48，改小反而失重 |
| 间隔页 | 标题 | 32 pt 加粗 | 模板占位符原生 32 |
| 结语页 | "谢谢！" | 模板原生 | 原样保留，不改字改号 |
| 正文页2 | 右侧文字框 | 默认 24 → **必须改为 15 或 12** | 模板默认值不合规，落入本页内容即须改 |
| 图片页 | 图注框 | 默认 28 → **必须改为 12** | 同上 |

> 一句话：**你能选字号的只有内容页的 28/15/12 三档；封面、间隔页、结语页的字号是模板给的，别动。**

**执行细则**
- 表格内**不分档**：表头与数据统一 12 pt，靠加粗与底色区分（见 5.1）。
- 图注、来源、单位（"万元""亿元"）统一 12 pt `#7F7F7F`，不单独设 10.5 pt。
- 关键数字不做超大化（原稿 36/44/54 pt 的巨型数字一律并入 L 档）。
- 一页内最多出现 2 档字号（L+S 或 L+M+S），不得只出现 M 档。

### 3.3 段落

| 属性 | 值 |
|---|---|
| 对齐 | 正文左对齐（**禁用两端对齐**，中文会松散）；卡片内可居中；表格数字右对齐 |
| 段前 / 段后 | 0 / 6 pt |
| 行距 | 见 3.2；正文 1.5 倍，表格与图注 1.0 |
| 缩进 | 无首行缩进；条目用悬挂缩进 0，符号见 3.4 |
| 文本框 | 自动换行开启，垂直居中（标题）或顶端对齐（正文）；内边距左右 0.25 cm、上下 0.13 cm |

### 3.4 列表符号

- 一级条目：`■` + 空格，`#0084D5`，12 pt（颜色跟随文字亦可）
- 二级条目：`·` 或 `–`，同正文色
- 条目编号：`1、2、3、`（中文顿号），与正文同字号
- 不用系统默认圆点 `•`（字号不一致时错位）

### 4.2 用色规则

| 场景 | 规范 |
|---|---|
| 页标题 | `#0084D5`，全篇统一（现状已一致，需显式锁定防换主题变色） |

| 白字 | 仅用于 `#0084D5`／`#005E99` 底色上 |

| 同页色数 | ≤ 4 色（含底色），图表序列 ≤ 4 个 |
| 渐变 | 仅允许 品牌蓝→深蓝 单方向；禁用多色渐变、图案填充 |

## 5. 表格规范

原稿 43 张表格存在 8 种表头底色、9–20 pt 八种字号、宽度 270–1214 px 的混乱，以下为唯一标准。

### 5.1 结构

| 项 | 规范 |
|---|---|
| 位置 | L 55.0，宽 1151.0（通栏）或按 1.3 分栏取宽；**不得左伸到 15.6、右伸到 1236** |
| 列数 | ≤ 12 列；超过则拆为两张表或改为"要点 + 数据卡" |
| 表头行 | 高 **36 px**；`#0084D5` 底、白字 **12 pt 加粗**、居中 |
| 数据行 | 高 **28 px**；12 pt 常规、`#000000`；单行显示，不换行 |
| 隔行 | 偶数行底 `#F4F4F4`（无隔行时用细横线代替，二者择一，全篇统一） |
| 合计行 | `#DDEBF7` 底，12 pt 加粗 |
| 边框 | **无竖线**；横线 0.75 pt `#D9D9D9`；外框不描边 |
| 内边距 | 左右 8 px（0.21 cm）、上下 4 px（0.11 cm） |
| 行数 | ≤ 15 行；超出拆表或转横向页 |

### 5.2 对齐与格式

| 内容类型 | 对齐 | 格式 |
|---|---|---|
| 文字（营销总部、区县、产品名） | 左 | — |
| 数值（销量、金额、门店数） | 右 | 千分位，1 位小数：`1,234.5` |
| 比率 / 达成率 | 居中 | 1 位小数：`103.0%` |
| 排名 / 序号 | 居中 | 整数 |
| 空值 | — | `—`（半角破折号），不留空、不写 0 |

### 5.3 单位

- 单位写在**表头**：`销量（亿元）`、`门店数（家）`，不在单元格内重复。
- 全表统一口径单位，不混用"万元/亿元"。

| 图表标题 | **关闭**（结论由页标题/导语承担） |
| 图例 | 顶部、靠左、12 pt；单系列不显示图例 |
| 数据标签 | 12 pt；仅标注首末值或极值，不全标 |
| 网格线 | 仅水平，0.75 pt `#E6E6E6`；无竖直网格线 |
| 坐标轴 | 轴线 0.75 pt `#BFBFBF` 或隐藏；刻度标签 12 pt `#7F7F7F` |
| 数据表 | 关闭（改用下方表格） |
| 序列配色 | 依序 `#0084D5` → `#BFBFBF` → `#78BE20` → `#C00000` |
| 数值格式 | 整数 `0`；负值 `0;[Red]-0`；百分比 `0.0%` |
| 图表区 | 无填充、无边框 |

### 6.3 常用组合

- **目标 vs 达成**：柱（目标，`#BFBFBF`）+ 柱（达成，`#0084D5`），标签只标达成。
- **月度趋势**：折线 `#0084D5`，2.25 pt，无数据点标记。
- **结构占比**：条形图优于饼图；饼图最多 5 块，其余合并为"其他"。

## 10. 文字写法（易错项）

| 项 | 规范 | 原稿问题示例 |
|---|---|---|
| 数字与单位 | 紧贴，不加空格 | `16. 62亿元` → `16.62亿元` |

| 正文编号 | `1、2、3、`（中文顿号） | — |
| 中文标点 | 全角（，。；：""） | — |
| 中英混排 | 中文与英文/数字之间不加空格 | `DTB 门店` → `DTB门店`（专有名词固定写法除外） |
| 日期 | `2026年8月31日` | `2025年12月25日` ✓ |
| 省略 | 用 `…`，不用 `...` | — |

## 13. 现状偏差基线（V1.8 实测，2026-11-01）

用配套脚本 `ppt_format_check.py` 对基准文件全量扫描，**共 2,877 处不符合本规范**：

| 类型 | 处数 | 集中位置 | 改造优先级 |
|---|---|---|---|
| 字号超出 3 档 | 1,903 | 全篇（14/11/10/10.5/9/18/20/24/36/40/44/54 共 14 种多余档位） | P0 |
| 字体不统一 | 743 | 第 9 页起 Microsoft YaHei；表格内 等线 125 处 | P0 |
| 使用禁用色 | 170 | 第 11 页 `#FEFFFE` 白字、第 10 页 `#C9C8C7` 灰字 | P1 |
| 页码缺失 | 22 | p1、7、9–14、16、18–19、23、25–27、33–36、38–40、42、45 | P1 |
| 表头底色不符 | 18 | p7/10/18/20–23/29/32/35… | P2 |
| 表头字重/字号 | 15 | p7/20–23/29/32/33/35/36/38/39 | P2 |
| 标题位置偏移 | 5 | p9、p40、p42、p45、p47 | P2 |
| 版式越界 | 1 | p46 误用 `1_Section Header` 版式，形成无标题页（建议删除该页） | P2 |

**建议改造顺序**：P0 两项（字号 + 字体）占全部偏差的 92%，且可批量执行，先做；P1 的页码与白字色影响投屏可读性，其次；P2 属精修，可在定稿前一次完成。

### 用法

```bash
python3 ppt_format_check.py "DTB项目专项汇报V1.8.pptx"          # 明细
python3 ppt_format_check.py "新文件.pptx" --brief              # 只看计数
```

脚本只读源文件，输出按类型分组的违规清单（附页码与原文），可直接作为改稿任务单。
